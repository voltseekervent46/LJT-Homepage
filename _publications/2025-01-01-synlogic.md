I am the first author of this work, which focuses on synthesizing verifiable reasoning data at scale for learning logical reasoning and beyond. Co-authors are Yuanxiang Fan, Zhuo Jiang, Han Ding, Yongyi Hu, Chi Zhang, Yiqi Shi, Shitong Weng, Aili Chen, Shiqi Chen, Yunan Huang, Mozhi Zhang, Pengyu Zhao, Junjie Yan, and Junxian He. A GitHub code repository is available.
